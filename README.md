Welcome to my personal portfolio website! 🌟 This is a sleek, modern web application showcasing my skills as a Frontend Developer. Built with cutting-edge technologies, it features smooth animations, responsive design, and an intuitive user experience.

## ✨ Features

- **🏠 Home Page**: Eye-catching introduction with animated photo and stats
- **📄 Resume**: Detailed overview of my skills, experience, and education
- **💼 Work**: Showcase of my projects and achievements
- **🛠️ Services**: What I offer as a developer
- **📞 Contact**: Easy ways to get in touch
- **📱 Responsive Design**: Looks great on all devices
- **🎨 Smooth Animations**: Powered by Framer Motion for delightful interactions
- **⚡ Fast Performance**: Optimized with Next.js for lightning-fast loading

## 🛠️ Tech Stack

- **Framework**: Next.js 14
- **UI Library**: React 18
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React & React Icons
- **Components**: Radix UI
- **Font**: Inter (optimized by Next.js)

## 🚀 Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/karhacter-home.git
   cd karhacter-home
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   # or
   bun dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result! 🎉
